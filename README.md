Linguage — Online Language Learning System
Linguage is a university system analysis and UI/UX design project for an online language learning platform. It brings courses, lessons, practice, progress tracking, and subscriptions into one place.
Figma Design - https://www.figma.com/design/dRLC0BOCLYjy1IvLS35wuo/Linguage?t=RguTKNRecdfGNjvm-1 


The designs include interfaces for learners and administrators.
Main Features
Learner Features
- Register, log in, and manage a profile.
- Choose a language and learning level.
- Browse courses and take lessons.
- Practice vocabulary, listening, speaking, and writing.
- View learning progress, study time, and learning streaks.
- Manage free and premium subscriptions.
Admin Features
- View a dashboard with user and subscription information.
- Add, edit, and delete lessons.
- Manage user accounts.
- Manage subscriptions and confirm cancellation requests.
System Analysis and Design
The project documentation includes:
- Functional and non-functional requirements.
- A use case diagram showing learner and administrator actions.
- An ER diagram showing entities and their relationships.
- Figma interface designs for learners and administrators.
- A final project report.
Main Entities
Admin, User, Language, Course, Lesson, Progress, and Subscription.
